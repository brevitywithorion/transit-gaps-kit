# Example: Lawrence, Kansas (origin city)

This folder holds **Lawrence-specific** prose and sample span outputs from the origin project.

- Live site (unchanged by this kit): https://lawrence-transit-gaps.pages.dev
- City config: `../../configs/lawrence.yaml`
- Sample span CSVs: `out_sample/`
- Content drafts: `content/` (summary, glossary, decisions)
- Methods notes: `assumptions.md`, `amendments.md`

Do not copy Lawrence ballot, sales-tax, or USD 497 school details into another city’s report. Use the config + GTFS pipeline instead.
